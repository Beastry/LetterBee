# 信笺模块 letter-kit

纸短情长里的「拆信」模块。它从生日页那类体验里抽出可以复用的产品能力，做成 Next.js 模块，不把整站搬成 Cloudflare Worker，也不携带任何私人信件。

## 模块边界

这个模块负责一封信被打开时的仪式和底稿：

- 开封：信封舞台、火漆、拆信刀、信笺展开。纯 CSS 伪 3D，没有 Three.js，也没有自定义光标或全屏闪光。
- 信纸：打字机逐字出现，可以有折进纸背的段落。气质跟着[产品概念](product-concept.md)走：慢、克制、像信，不像聊天。
- 区块：`letter`、`photos`、`voice`、`video`、`timeline`。`hero`、`ending`、`easter` 也有实现，可以当扉页、结尾和暗记。
- 按日解锁：`unlockAt` 使用 `YYYY-MM-DD`。到了这一天（含当天）才算到期。收信页在服务端按信笺时区过滤，未到期的正文、图片地址和声音地址都不会发给浏览器。
- 私密访问：可配置的口令盘、服务端 scrypt 哈希、签名会话、同一地址 10 分钟内 5 次失败后限流。提示文案写在底稿里。
- 背景声：歌单可上传，顺序或随机，曲目之间交叉淡化。语音或影像播放时把配乐压低。
- 编辑端：增删、排序区块，拖拽上传媒体，侧栏按日期预览。第一版把底稿写成本地 JSON，媒体放在 `public/letter-media`。接口留了目录环境变量，还没有接对象存储。

这些仍然不属于本模块：

- 寄出、邀请认领、距离延迟、邮路地图
- 账号体系替换
- 生产部署
- 生日页仓库里的私人内容、口令或特定信物文案

## 本地怎么走一遍

样例信在 `/letters/sample`。样例口令是 `7041`，只为了本地把流程走通，不是任何真实口令。编辑端可以换成别的，仓库里只留哈希。

```bash
pnpm install
pnpm test
pnpm dev
```

1. 打开 `/letters/sample`，在口令盘输入 `7041`。
2. 把拆信刀拖到火漆上，或点「用拆信刀划开火漆」。
3. 看信纸、照片、声音、影像、邮路和背景声。未到期的后记只会显示启封日。
4. 登录并设置邮局后，打开 `/app/write`（或 `/letters/sample/edit`）。
5. 改一段话、拖拽调整区块，保存。侧栏会按选定日期预览。刷新收信页能看到已保存、且已经到期的内容。

## 配置

底稿文件默认是 `data/letters/<slug>.json`。样例是 `data/letters/sample.json`。

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `LETTER_DATA_DIR` | 底稿目录 | `data/letters` |
| `LETTER_MEDIA_DIR` | 媒体文件目录 | `public/letter-media` |
| `LETTER_MEDIA_BASE` | 媒体 URL 前缀 | `/letter-media` |
| `LETTER_SESSION_SECRET` | 签收信会话。生产环境必填，至少 16 位 | 开发环境使用内置的非生产密钥 |

口令字段：

- `gate.hint`：收信页上的提示
- `gate.dials`：位数，1 到 8
- `gate.charset`：每一位可以转到的字符，不能有空格或重复
- `gate.passphraseHash`：`scrypt$盐$哈希`。编辑端留空「新口令」时保持原哈希；改了位数或字符表就必须设新口令

区块和段落、照片、邮路节点都可以带 `unlockAt`。缺省表示不按日期上锁。`hidden: true` 的段落会发给已经到期的收信人，但要在信纸上点开，这是阅读节奏，不是日期锁。

背景声在 `bgm`：`mode` 为 `sequence` 或 `shuffle`，`crossfadeMs` 为 200 到 5000。上传的文件落在 `public/letter-media/<slug>/uploads/`，这个目录不进 git。

限流记在当前进程内存里，重启会清零，多实例之间不共享。

## 测试

`pnpm test` 覆盖按日过滤（整块和嵌套正文都不会漏出）、口令哈希、会话签名与过期、失败限流，以及本地底稿的读写。
